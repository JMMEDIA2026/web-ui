## 1. 한 장 요약

### 1-1. 무엇을 하는 사업인가
**라오스에 사는 한인과 라오스를 찾는 한국인 자유여행객을 위한 "정보 + 예약 연결" 플랫폼**입니다.
직접 투어를 운영하지 않고, 정보를 제공하면서 예약은 현지 협력업체와 **협업**으로 처리합니다.

### 1-2. 핵심 서비스 (손글씨 메모 반영)
| 영역 | 방식 | 중요도 |
|---|---|---|
| 자유여행 정보 | 사이트에서 정보 제공 | 기본 |
| 마사지 | 예약 가능, 업체와 협업 | 보통 |
| **골프 부킹 + 픽업 서비스** | 골프장·픽업 업체와 협업 | **높음 (메모에서 동그라미)** |
| 티켓팅 예약 | 골프 부킹 중심으로 연결 | 높음 |
| 여행 코스 예약 | 업체와 협업 | 보통 |
| **차량 예약 = 오토바이 렌트** | 렌트 업체와 협업 | **높음 (메모에서 동그라미)** |
| **환전** | 환전업체 보유, 오늘의 환율 표시 | 높음 (신규 요청) |
| 한인 업체 디렉토리 | 식당·마트·병원·학교·부동산·구인 | 기본 |
| 생활 가이드 | 비자·면허·통신·병원·대사관·은행 | 기본 |
| 광고 | 배너·추천 업체·프리미엄 등록 | 수익원 |
| **하지 않는 것** | **패키지 투어 (메모: 투어 → X)** | - |

### 1-3. 수익은 어디서 나오나
1. **광고·노출 수수료**: 추천 업체, 배너, 프리미엄 등록 (월 정액)
2. **예약 연결 수수료**: 골프·마사지·렌트·티켓 예약 성사 시 업체로부터 (🟡 방식·요율 미정)
3. **환전업체 제휴 노출**: 환전소 추천 노출 (🟡 방식 미정)

### 1-4. 현재 상태
- ✅ 사이트 운영 중: https://laos.joybox.day
- ✅ 홈, 업체 목록·상세, 환전·환율, 예약, 생활 가이드, 광고 안내·문의 페이지
- ✅ **관리자 페이지**, **협력업체 예약확인 페이지**, **고객 예약 폼**, 광고 문의 저장
- ✅ 실시간(일 단위 갱신) 기준 환율 표시와 원→킵 계산기
- 🟡 업체·가이드 내용은 아직 **"예시"** (실제 정보 입력 전)
- 🟡 협력업체 0곳 (예약 폼은 업체 등록 후 열림)
- 🔴 새 예약 알림 없음, 가이드 본문 미작성, 법·규제 미확인

### 1-5. 지금 가장 중요한 3가지
1. **실제 협력업체 5곳 이상 확보** (오토바이 렌트, 골프, 환전, 마사지, 식당 순)
2. **예약 알림 연결** (슬랙 또는 카카오톡) — 놓치는 예약이 없어야 신뢰가 쌓입니다
3. **법·규제와 책임 범위 확인** — 예약 대행과 환전 연결은 책임 문제가 따릅니다

## 2. 사업 배경과 문제 정의

### 2-1. 출발점
- 대표님이 현재 라오스에 체류 중이며, 와 보니 **한인 커뮤니티 사이트가 없다**는 것이 출발점입니다. (✅ 대화 내용)
- 한인 정보는 카카오톡 오픈채팅, 페이스북 그룹 등에 흩어져 있을 가능성이 높습니다. (🟡 현지 조사로 확인 필요)

### 2-2. 해결하려는 문제 (🟡 가정, 인터뷰로 검증)
| 문제 | 겪는 사람 | 지금의 대처 | 라오스모아의 해법 |
|---|---|---|---|
| 비자·면허·통신 같은 생활 정보가 흩어져 있고 오래됨 | 거주 한인 | 지인에게 묻기, 카톡방 검색 | 한 곳에 정리된 최신 가이드 |
| 믿을 만한 한인 업체를 찾기 어려움 | 거주 한인, 여행자 | 소개와 입소문 | 확인된 업체 디렉토리 |
| 골프·마사지·오토바이 렌트를 예약할 때 언어와 신뢰 문제 | 자유여행객 | 현지 업체에 직접 연락, 에이전시 | 한국어 예약 요청과 협력업체 확인 |
| 환전소 환율이 곳마다 달라 불안함 | 거주 한인, 여행자 | 여러 곳 방문, 지인 문의 | 기준 환율 참고 + 한인 환전업체 안내 |
| 한인 업체는 고객에게 알릴 채널이 부족함 | 업체 사장님 | 입소문, SNS | 노출·광고 채널 |

### 2-3. 기회
- 자유여행 중심으로 가면 **패키지 투어사와 정면 경쟁하지 않고** 정보와 연결로 가치를 낼 수 있습니다.
- 예약을 직접 운영하지 않으므로 **재고·인력·장비 부담이 없습니다.**
- 데이터(예약, 문의, 검색)가 쌓일수록 협력업체에 줄 수 있는 가치(노출 성과 보고)가 커집니다.

### 2-4. 아직 모르는 것 (조사 항목)
- 🟡 라오스 거주 한인 규모와 분포 (비엔티안 외 방비엥, 루앙프라방, 빡세 등)
- 🟡 한국인 여행객의 연간 방문 규모와 주요 방문지
- 🟡 기존 경쟁 서비스(카페, 카톡방, 여행 에이전시, 해외 예약 플랫폼)의 범위와 약점
- 🟡 협력업체가 지불할 의향이 있는 광고비·수수료 수준

## 3. 비전·미션·핵심 가치

| 구분 | 내용 |
|---|---|
| 비전 | 라오스에서 한국어로 가장 먼저 찾게 되는 생활·여행 정보 허브 |
| 미션 | 먼저 정착한 한인의 경험을 모아, 처음 오는 사람이 막히지 않게 한다 |
| 한 줄 소개 | "라오스 생활, 한인끼리 묻고 나눕니다." (✅ 사이트 대표 문구) |

### 핵심 가치
1. **확인한 정보만 싣는다**: 제도 정보는 관할 기관의 최신 안내를 확인한 내용만 게시합니다.
2. **광고는 광고라고 표시한다**: 광고와 일반 정보를 항상 구분합니다. (✅ 사이트에 반영)
3. **참고용은 참고용이라고 말한다**: 환율은 기준 환율임을 명시합니다. (✅ 반영)
4. **업체와 고객 모두 이기는 구조**: 업체는 노출과 예약을, 고객은 신뢰와 편의를 얻습니다.
5. **작게 시작해서 검증한다**: 기능을 늘리기 전에 실제 사용을 확인합니다.

## 4. 목표 고객

### 4-1. 고객군
| 고객군 | 설명 | 주요 니즈 | 우선순위 |
|---|---|---|---|
| A. 자유여행객 | 패키지 없이 라오스를 여행하는 한국인 | 여행 정보, 골프·마사지·오토바이·티켓 예약, 환율 | **1순위 (메모 기준)** |
| B. 거주 한인 | 주재원, 교민, 장기 체류자 | 생활 정보, 믿을 만한 업체, 환전, 구인 | 1순위 |
| C. 협력업체 | 한인 대상 사업장, 현지 업체 | 고객 유입, 예약 관리, 광고 | 수익 대상 |
| D. 예비 정착자 | 라오스 이주·파견을 준비하는 사람 | 비자, 주거, 학교, 병원 정보 | 2순위 |

> 🟡 메모는 여행자 중심으로 보이는데 지금 사이트는 거주 한인 위주로 시작했습니다. **두 고객군을 함께 겨냥**하는 것으로 가정했습니다. (19장 의사결정 항목 참조)

### 4-2. 페르소나 (예시, 인터뷰로 교체)

**페르소나 1 — 자유여행객 민수 (30대, 친구 2명과 여행)**
- 목표: 비엔티안에서 골프 한 번, 마사지, 오토바이로 근교 이동
- 불편: 영어·라오어가 서툴러 예약이 불안, 가격이 적정한지 모름, 환전소 선택이 막막
- 라오스모아에서 하는 일: 여행 정보 읽기 → 골프·오토바이 예약 요청 → 카톡으로 확정 연락 받기 → 환율 확인

**페르소나 2 — 주재원 가족 지영 (40대, 초등생 자녀)**
- 목표: 정착 초기에 학교·병원·마트·심카드를 빨리 해결
- 불편: 정보가 카톡방에 흩어져 있어 찾기 어려움
- 라오스모아에서 하는 일: 생활 가이드 읽기 → 한인 업체 검색 → 업체 연락처 확인

**페르소나 3 — 협력업체 사장님 철수 (오토바이 렌트)**
- 목표: 한국 손님 확보, 예약 관리 단순화
- 불편: 한국어 고객 응대와 홍보가 어려움
- 라오스모아에서 하는 일: 협력업체 등록 → 접속 코드로 로그인 → 예약 확인·확정 → 노출 성과 확인

**페르소나 4 — 환전소 운영자 영희**
- 목표: 한국 손님에게 환전소를 알리고 신뢰 확보
- 라오스모아에서 하는 일: 환전업체로 등록 → 오늘 시세 공개(향후 기능) → 추천 노출

## 5. 서비스 구성과 범위

### 5-1. 서비스 지도

```
[정보] ─────────────┐
 ├ 자유여행 정보       │
 ├ 생활 가이드          │
 └ 오늘의 환율          ├──▶ 신뢰와 방문 유입 ──▶ [예약 연결] ──▶ 수수료
                       │                         ├ 골프 부킹 + 픽업
[디렉토리] ───────────┘                         ├ 오토바이(차량) 렌트
 ├ 한인 업체(식당·마트·병원·학교·부동산·구인)     ├ 마사지
 └ 환전업체                                      ├ 티켓팅
                                                 └ 여행 코스
[광고] ──▶ 추천 업체 · 배너 · 프리미엄 등록 ──▶ 광고 수익
```

### 5-2. 하는 것
- 정보 제공 (여행, 생활, 환율)
- 협력업체 소개와 예약 **요청 접수·전달·확정 확인**
- 업체 디렉토리와 광고 노출
- 환전업체 안내

### 5-3. 하지 않는 것 (✅ 메모: 투어 → X)
- **패키지 투어 기획·판매·인솔**
- 항공권·숙박 직접 판매 (🟡 현 단계에서는 범위 밖으로 가정)
- 직접 환전 업무 (환전은 환전업체가 수행, 사이트는 안내·연결만)
- 직접 차량·오토바이 소유·임대 (렌트 업체가 수행)

> **"하지 않는 것"을 분명히 하는 이유**: 직접 운영하지 않으면 사고·분쟁·인허가 책임이 크게 줄어듭니다. 예약 연결 서비스의 책임 범위는 8-5, 17장에서 다시 정리합니다.

### 5-4. 서비스별 상세

#### (1) 자유여행 정보
- 목적: 자유여행객이 사이트에 처음 들어오는 이유를 만든다 (검색 유입)
- 콘텐츠 예: 비엔티안 반나절·1일 코스, 방비엥·루앙프라방 이동, 교통(툭툭·택시·오토바이), 환전 요령, 안전 수칙, 날씨와 계절별 팁
- 🟡 필요한 것: **현지 경험 기반 원고와 사진** (메모: "정보 → 필요")
- 상태: 🟡 가이드 틀만 존재 (본문 미작성)

#### (2) 골프 부킹 + 픽업 서비스 ⭐
- 방식: 골프장·픽업 업체와 협업 (골프장 직접 계약 또는 에이전시 경유 🟡 확인 필요)

- 필요한 정보: 골프장 목록, 홀 수, 그린피 범위(🟡 업체 확인), 캐디·카트 포함 여부, 픽업 가능 지역, 예약 마감 시간

## 8. 예약 운영 프로세스

### 8-1. 전체 흐름

```
고객: /reserve 에서 업체·날짜·인원·연락처 입력
   │  (예약번호 발급, "아직 확정 아님" 안내)

   ▼

   ▼

```

### 8-2. 예약 상태 정의 (✅ 구현)
| 상태 | 의미 | 누가 바꾸나 |
|---|---|---|
| 대기 (pending) | 고객이 요청, 업체 미확인 | 자동 |
| 확정 (confirmed) | 업체가 가능하다고 확인 | 협력업체·관리자 |
| 거절 (declined) | 업체가 불가 | 협력업체·관리자 |
| 완료 (completed) | 이용이 끝남 | 협력업체·관리자 |
| 취소 (cancelled) | 관리자가 취소 처리 | 관리자만 |

- 취소된 예약은 업체가 다시 바꿀 수 없습니다. (✅ 구현·시험 완료)

### 8-3. 응대 기준 (🟡 제안)
| 단계 | 담당 | 기준 |
|---|---|---|
| 새 예약 확인 | 업체 | 영업시간 기준 3시간 이내 |
| 확정 안내 | 업체 또는 운영자 | 확정 즉시 고객 연락처로 |
| 미확인 예약 점검 | 운영자 | 하루 2회(오전·오후) 관리자 화면 확인 |
| 24시간 무응답 | 운영자 | 업체에 직접 연락, 안 되면 고객에게 대안 안내 |

### 8-4. 취소·변경·노쇼 정책 초안 (🔴 업체와 협의·확정 필요)
- 고객 취소: 이용 N일(시간) 전까지 무료, 이후는 업체 규정에 따름
- 날씨·불가항력(골프 등): 업체 규정에 따라 일정 변경 또는 환불
- 노쇼: 업체 규정에 따라 처리, 반복 시 예약 제한 (🟡 구현 필요)
- **사이트에는 "예약 요청이며 업체 확정 후 성립한다"를 항상 표시** (✅ 폼에 반영)

### 8-5. 책임 범위 (🔴 중요, 약관에 반영 필요)
- 라오스모아는 **정보 제공과 예약 연결**을 하며, 서비스 이행(골프 라운딩, 마사지, 오토바이 대여)은 협력업체가 합니다.
- 서비스 중 사고·분쟁·파손은 원칙적으로 **업체와 고객 간 계약 사항**이라는 점을 약관에 명시하되, 이 문구의 효력은 🔴 전문가 확인이 필요합니다.
- **오토바이**: 안전 수칙(헬멧, 면허, 보험, 야간 운행) 안내를 예약 단계에서 필수 표시하세요.
- 고객 개인정보(이름·연락처)는 예약 처리 목적에만 사용하고, 협력업체에는 **해당 예약 건만** 전달합니다. (✅ 구조상 자기 예약만 열람)

### 8-6. 예약 정보 보관

- 안내 문구: "국제 기준 환율이며 실제 환전소 환율과 다를 수 있습니다."
- 예시 값(2026-11-25 기준 조회): 1달러 약 22,294킵, 1,000원 약 16,600킵, 1달러 약 1,343원 (🟡 참고용 확인 값, 실시간으로 바뀜)

### 9-2. 환전업체 연결 (대표님이 환전업체 보유 ✅)
- 환전 카테고리를 만들고 업체를 "환전업체"로 등록
- 현재 "예시 환전소 G"가 자리를 대신하고 있음 → **실제 업체 정보로 교체 필요**
- 필요 정보: 상호, 위치(주소·지도), 영업시간, 연락처(카카오톡), 취급 통화(원·달러·킵 등), 최소·최대 환전 금액 정책, 수수료 유무

### 9-3. 핵심 제안: 환전소 "실제 오늘 시세" 표시 (추천)
기준 환율만으로는 환전소 선택에 도움이 부족합니다. 환전업체가 매일 **자기 매입·매도 시세**를 입력하면 사이트에 "○○ 환전소 오늘 시세"로 보여 줍니다.
- 협력업체 페이지에 "오늘 시세 입력" 기능 추가 (🟡 개발 필요)
- 입력 시간과 "시세는 변동될 수 있음" 문구 표시
- 효과: 사이트에 **매일 들어올 이유**가 생기고, 환전소 추천 노출 광고의 근거가 됩니다.

### 9-4. 환전 서비스의 리스크

## 10. 수익 모델

### 10-1. 수익원 개요

| 수익원 | 대상 | 방식 | 시작 시점 |
|---|---|---|---|
| 프리미엄 업체(추천 노출) | 모든 업체 | 월 정액 | 사이트에 업체 10곳·방문자 확보 후 |
| 배너 광고 | 큰 업체, 브랜드 | 기간제(주·월) | 방문자 수치 확보 후 |
| 예약 연결 수수료 | 예약 협업 업체 | 성사당 정액 또는 % | 시범 예약 검증 후 |

| (후순위) 구인 공고 | 한인 업체 | 건당 | 후순위 |

### 10-2. 광고 상품 (✅ 사이트에 자리와 안내문 구현)
| 상품 | 위치 | 규격 | 비고 |
|---|---|---|---|
| 메인 배너 | 홈, 카테고리 아래 | PC 970×250, 모바일 320×100 | 가장 큰 노출 |
| 사이드 배너 | 게시판·상세 옆 | 300×250 | |

| 추천 업체 | 업체 목록 최상단 | 노란 테두리·"추천·광고" 배지 | 정렬 우선 (✅ 구현) |
| 프리미엄 등록 | 업체 상세 | 사진 여러 장·메뉴·문의 버튼 | 일부 미구현 |

### 10-3. 가격 정하는 방법 (순서)
1. 협력업체 3~5곳에게 "한 달 노출에 얼마를 낼 수 있는지" 직접 묻기
2. 업체가 현재 쓰는 홍보 비용(전단, SNS 광고 등)과 비교
3. 첫 3개월은 **무료 또는 시범 가격**으로 노출 성과(조회, 문의, 예약)를 보고서로 제공
4. 성과가 보이면 정상 가격으로 전환

### 10-4. 예약 수수료 설계 옵션 (🟡 선택 필요)
| 옵션 | 장점 | 단점 |
|---|---|---|
| 성사당 정액 | 계산 쉬움, 업체 이해 쉬움 | 객단가 차이를 반영 못함 |
| 성사 금액의 % | 객단가에 비례 | 실제 결제액 파악이 어려움 |
| 월 정액(구독) | 정산 단순, 예측 가능 | 성과가 낮은 달 업체 불만 |
| 혼합(월 정액 + 소액 수수료) | 균형 | 설명 복잡 |

> **추천**: 초기에는 **월 정액 또는 무료 시범**으로 시작하고, 예약이 쌓여 **성사 건수와 금액이 확인되면** 수수료로 전환하세요. 정산 근거(예약 완료 기록)는 이미 시스템에 남습니다.

### 10-5. 정산 방식 (🔴 결정 필요)
- 고객 결제는 **현장 결제**로 시작하는 것이 간단합니다. (온라인 결제는 법·정산 부담이 큼)
- 수수료는 업체와 **월 단위 정산**(예약 완료 건수 기준), 관리자 화면에서 내역 확인
- 🟡 정산용 집계 화면(월별·업체별)은 미구현

### 10-6. 손익 구조 (변수만 정의, 값은 조사 후)
```
월 수익 = (프리미엄 업체 수 × 월 정액)
        + (배너 계약 수 × 단가)
        + (월 완료 예약 수 × 건당 수수료)
        + (환전소 추천 계약 × 월 정액)

월 비용 = 도메인·호스팅 (현재 매우 낮음, 🟡 요금제 확인)
        + 콘텐츠 제작비(촬영·번역·원고)
        + 영업·운영 인건비
        + 광고·홍보비
        + 결제·정산 수수료(결제 도입 시)
```
- 현재 호스팅은 Cloudflare Workers·D1 무료 한도 내에서 운영 중입니다. 🟡 방문·예약이 늘면 유료 요금제 필요 여부를 확인하세요.
- **손익분기**: 월 비용 대비 필요한 프리미엄 업체 수를 계산해 두면 영업 목표가 명확해집니다. (값은 조사 후)

## 13. 기술·보안·운영 구조

### 13-1. 구성 (✅ 현재)
| 구성 | 사용 기술 |

| 아이콘·폰트·사진 | Microsoft Fluent Emoji(MIT), Pretendard(CDN), 위키미디어(CC BY-SA 4.0) |

### 13-2. 데이터 모델 (✅)
- `partners`: 협력업체(로그인 ID, 이름, 분야, 연락처, 접속 코드 해시, 활성 여부)
- `reservations`: 예약(번호, 업체, 고객명, 연락처, 서비스, 날짜, 인원, 요청, 상태, 업체 메모, 시각)
- `inquiries`: 광고·제휴 문의
- `settings`: 관리자 비밀번호(해시)
- `rate_hits`: 로그인·예약 요청 횟수 제한 기록

### 13-3. 보안 현황 (✅ 구현·시험 완료)
- 비밀번호·접속 코드: PBKDF2-SHA256 해시 저장 (원문 복구 불가)
- 세션: 서명된 쿠키(HttpOnly·Secure·SameSite), 8시간 만료
- 권한 분리: 관리자 ≠ 협력업체, **협력업체는 자기 예약만** 열람·수정
- 비활성화한 업체는 이미 로그인한 세션도 즉시 차단
- 로그인 5회 실패 시 10분 잠금, 예약·문의 시간당 횟수 제한
- 다른 사이트에서 보낸 요청(CSRF) 차단, 스팸 방지 숨김 필드
- 관리자·협력업체 주소는 검색 엔진 노출 차단
- 시험: API 60개 항목 + 운영 14개 항목 통과

### 13-4. 반드시 처리할 보안 사항 (🔴)
1. **관리자 초기 비밀번호 변경** (대화에 노출됨) — `/admin/settings`
2. **Cloudflare API 토큰 재발급** (캡처에 값이 노출됨) — 이후 배포 시 새 값 필요
3. 관리자 비밀번호는 길고 고유하게, 공유하지 않기
4. 협력업체 접속 코드는 카톡 등으로 전달 후 업체가 보관, 분실 시 재발급
5. 관리자 계정이 1개라 🟡 운영자가 늘면 계정 분리·접속 기록 기능 필요

### 13-5. 운영·백업
